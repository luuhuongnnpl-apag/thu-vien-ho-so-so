Kết nối Kho Google Drive & Đồng bộ Tự động

Gắn tài liệu từ Google Drive mà không cần tải mới:
  • Cách 1 (Dán link trực tiếp): Vào mục "+ Gắn / Tải Tài liệu Drive", chọn tab "Gắn từ Google Drive (Không cần tải mới)" rồi dán link file hoặc danh sách link.
  • Cách 2 (Quét tự động cả thư mục Drive): Nhập ID thư mục gốc Google Drive và URL Google Apps Script bên dưới, sau đó nhấn nút "Quét tự động từ Drive" để hệ thống tự lấy toàn bộ file có sẵn trong Drive lên web.

Chuyển Văn bản Ghi chú vào File / Thư mục cụ thể

Văn bản ghi chú đang chọn:

1. Chuyển vào một File (Hồ sơ) cụ thể trong Thư viện

Chọn hồ sơ / file cụ thể để đính kèm văn bản ghi chú này vào hoặc gộp nội dung soạn thảo vào thẳng trong file đó:

2. Chuyển File văn bản này vào Thư mục / Bộ sưu tập cụ thể

3. Xuất văn bản đã soạn thành File cụ thể về máy (.DOC Word / .TXT / PDF)
