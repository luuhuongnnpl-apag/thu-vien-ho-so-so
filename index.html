Kết nối Kho Lưu Trữ Google Drive & Cloud Database

Đồng bộ dữ liệu chung khi ban hành Web công khai (GitHub Pages / Firebase):
  • Google Apps Script Bridge (Khuyên dùng): Vừa tự động upload file lên Google Drive, vừa lưu cơ sở dữ liệu danh mục hồ sơ ngay trên Google Drive để mọi người truy cập web đều thấy.
  • Firebase Realtime Database (Tùy chọn): Lưu cơ sở dữ liệu danh mục hồ sơ thời gian thực trên Firebase.
Mã nguồn đã tạo sẵn tại file google-apps-script/Code.gs trong thư mục dự án.

Chuyển đổi vai trò (Có bảo vệ mật khẩu trên Web công khai):

Chính sách bảo mật Thư viện Hồ sơ:

Hướng dẫn Ban hành Web Công khai (GitHub Pages & Firebase)

Dự án đã được cấu hình sẵn sàng 100% để ban hành công khai!
Đã tích hợp sẵn file cấu hình .github/workflows/deploy.yml (cho GitHub Pages), firebase.json (cho Firebase Hosting) và js/cloud-config.js (đồng bộ CSDL đám mây).

Cách 1: Ban hành miễn phí bằng tài khoản GitHub (Không cần cài phần mềm - 2 phút)

  1. Đăng nhập vào github.com/new để tạo 1 Repository mới (ví dụ đặt tên: thu-vien-ho-so, chọn Public).
  2. Nhấn vào dòng "uploading an existing file" trên màn hình GitHub.
  3. Kéo thả toàn bộ các file và thư mục trong h:\Drive của tôi\12. ANTIGRAV (gồm index.html, thư mục css, js, .github) vào cửa sổ trình duyệt rồi nhấn Commit changes.
  4. Vào mục Settings của Repository → chọn Pages (menu bên trái) → ở mục Build and deployment (Source) chọn Deploy from a branch → nhánh main → nhấn Save.
  5. Sau 30 giây, bạn sẽ nhận được đường link công khai vĩnh viễn: https://<ten-ban>.github.io/thu-vien-ho-so/

Cách 2: Kết nối Cơ sở dữ liệu chung trên Firebase hoặc Google Drive

Để khi bạn thêm/sửa hồ sơ trên web công khai thì mọi người truy cập từ máy khác đều thấy ngay:

  • Dùng Google Drive làm CSDL chung: Dán mã trong file google-apps-script/Code.gs lên script.google.com → Bấm Triển khai (Ứng dụng Web) → Dán URL vào biến gasWebAppUrl trong file js/cloud-config.js.
  • Hoặc dùng Firebase Realtime Database: Vào console.firebase.google.com → Tạo Project → Bật Realtime Database (chế độ Test Mode) → Copy đường link https://...-default-rtdb.firebaseio.com dán vào biến firebaseDbUrl trong file js/cloud-config.js.
